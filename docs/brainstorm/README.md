# 壁打ちの記録

設計書（[docs/design.md](../design.md)）を書く前の、アイデア出しや議論を残す場所。

## 使い方

- **1回の壁打ちにつき1ファイル**。名前は `YYYY-MM-DD_<話題>.md`（例：`2026-10-24_theme.md`）
- 書き方は [_template.md](_template.md) をコピーして使う
- 結論が出ていなくてもよい。出たアイデア、却下した案とその理由、未決の論点を残す
- **決まったことは設計書に反映する**。反映したら、その壁打ちファイルの「設計書への反映」欄にチェックを入れる
- 機密情報（APIキー、個人情報など）は書かない。このリポジトリは public
