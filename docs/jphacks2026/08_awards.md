# JPHACKS Awards

> 出典: [JPHACKS2026 参加者ガイドライン / JPHACKS Awards](https://app.notion.com/p/ecc30d2bd1848317a5a9819d7db660f1)（Notion 最終更新 2026-10-06、取得 2026-10-24）

JPHACKS に参加すると得ることができる Award（賞）について。スポンサー企業の賞は [Sponsor Award](12_sponsor-awards.md) を参照。

## 1. Hack Day Audience Award（Best Hack Day Award）

JPHACKS Hack Day に参加したチームから、オーディエンス投票により各会場1チームずつ選出されます。

| 項目 | 内容 |
| --- | --- |
| **選出チーム** | 各会場 1チーム |
| **選出方法** | 各会場にて実施されたピッチ・デモをもとに、参加者及びスポンサーで構成されるオーディエンス投票によって、最も多くの票を獲得したチーム |
| **選出条件** | ・JPHACKS Hack Day に参加すること<br>・JPHACKS Hack Day にて最終ピッチ・デモを実施すること |
| **賞の内容** | ・Amazon商品券 5,000円分 |

## 2. JPHACKS Finalist Award

JPHACKS に参加したチームの中から、審査委員会によってオンライン審査を実施し、最も優れたと判断された15チームに、Award Day への進出権が与えられます。

| 項目 | 内容 |
| --- | --- |
| **選出チーム** | 合計15チーム |
| **選出方法** | JPHACKS Hack Day 終了後に、審査委員会によってオンライン審査を実施 |
| **選出条件** | ・JPHACKS Hack Day に参加すること<br>・JPHACKS Hack Day にて最終ピッチ・デモを実施すること<br>・[必要提出物](05_submission.md) が正しく提出されていること |
| **賞の内容** | ・オープンバッジの授与（後日）<br>・Amazon商品券 1万円分 |

## 3. JPHACKS Innovator 認定

JPHACKS Award Day にてピッチ、展示会を実施したチームの中から、組織委員会及び審査委員会によって優れていると判断されたプロダクト及びチームが JPHACKS Innovator 認定として表彰されます。

| 項目 | 内容 |
| --- | --- |
| **選出チーム** | 合計6〜8チーム程度（変動可能性あり） |
| **選出方法** | Award Day のピッチ・展示会終了後に、組織委員会及び審査委員会によって審査会を実施して決定 |
| **選出条件** | ・Award Day にてピッチをすること<br>・Award Day にて展示会を実施すること |
| **賞の内容** | ・公式HPへの Innovator としての紹介 |

## 4. JPHACKS Best Audience Award

Award Day にてピッチ、展示会を実施したチームの中から、オーディエンス（観覧・スポンサー・組織委員会・審査委員会）の投票によって、最も票を獲得したチームが表彰されます。

| 項目 | 内容 |
| --- | --- |
| **選出チーム** | 1チーム |
| **選出方法** | Award Day のピッチ・展示会終了後に実施したオーディエンス審査にて、最も多くの票を獲得したチーム |
| **選出条件** | ・Award Day にてピッチをすること<br>・Award Day にて展示会を実施すること |
| **賞の内容** | ・JPHACKS特別アイテムの贈呈<br>・公式HPへの掲載<br>・継続開発支援金 10万円相当 |

## 5. JPHACKS Best Hack Award

Award Day にてピッチ、展示会を実施したチームの中から、組織委員会及び審査委員会によって審査基準に則った採点を実施し、集計の結果最も高得点を獲得したチームが JPHACKS Best Hack Award および **デジタル大臣奨励賞** として表彰されます（Best Audience Award とのダブル受賞もあり）。

| 項目 | 内容 |
| --- | --- |
| **選出チーム** | 1チーム |
| **選出方法** | Award Day のピッチ・展示会終了後に、組織委員会及び審査委員会による審査基準に則った採点の集計により決定 |
| **選出条件** | ・Award Day にてピッチをすること<br>・Award Day にて展示会を実施すること |
| **賞の内容** | ・JPHACKS特別アイテムの贈呈<br>・公式HPへの掲載<br>・継続開発支援金 30万円相当 |

## 6. JPHACKS 審査委員特別賞

Award Day にてピッチ、展示会を実施したチームの中から、組織委員会及び審査委員会によって、何かしらの観点で突出している点を評価されたチームが表彰される場合があります。

| 項目 | 内容 |
| --- | --- |
| **選出チーム** | 当日決定 |
| **選出方法** | Award Day のピッチ・展示会終了後に、組織委員会及び審査委員会によって審査会を実施して決定 |
| **選出条件** | ・Award Day にてピッチをすること<br>・Award Day にて展示会を実施すること |
| **賞の内容** | ・公式HPへの掲載<br>・継続開発支援金 10万円相当 |
