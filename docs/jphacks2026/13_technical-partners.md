# テクニカルパートナーからの提供物

> 出典: [JPHACKS2026 参加者ガイドライン / テクニカルパートナーからの提供物](https://app.notion.com/p/45330d2bd1848350942301aa8f45550d)（Notion 最終更新 2026-10-06、取得 2026-10-24）

JPHACKS 参加者は、テクニカルパートナーから開発力を高める製品支援を受けることができます。利用を希望する場合は、各利用申請方法に従って申請してください。Slack でも質問を受け付けています。

## 学習支援

全国100社を超える国内IT企業が新人研修に利用しているオンラインプログラミングカリキュラムを無償提供（→ [テクニカル学習コース](15_learning-courses.md)）。

- 対象者：JPHACKS エントリー者（希望者全員）

## ハッカソン・チーム開発支援

### Slack

Slack の有償プラン（Standard プラン）を180日間無償提供。

- 対象者：JPHACKS Hack Day 参加者全員
- 対象期間：2026年8月末〜2026年11月30日

### Zoom

各種イベント開催用の有償 Zoom アカウントを特別プランにて提供。

- 対象者：JPHACKS 運営事務局
- 提供期間：2026年10月1日〜10月31日
