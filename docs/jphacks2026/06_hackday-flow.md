当日タイムラインの詳細は [開催概要](01_overview.md#当日タイムライン) を参照。

## Hack Day参加までの過ごし方

### 1. 事前学習で個人のスキルを磨く

JPHACKSで利用できる学習ツール:

- Track（Web開発 HTML / CSS / JavaScript / PHP / GitHub / AI駆動開発）
- 利用を希望する場合は、Slack の `#プログラミング学習チャンネル` を確認してください（詳細は [テクニカル学習コース](15_learning-courses.md)）

### 2. Slackのプロフィールを作成する

- Slack のアカウント設定を [事前準備物](02_preparation.md#設定) に従って完了させる

### 3. 各チームで顔合わせ・アイデア練りをする

#### 随時Slackでチーム専用チャンネルを確認する

- チームごとに、プライベートチャンネルに随時招待されます
- 個人エントリーの方は、運営が編成したチームで当日参加します

#### チーム内で顔合わせ・アイデア出しをする

- Slack のハドルミーティング、チャット等を活用しながら、当日までに顔合わせやアイデア出しをしておくことを推奨
- ※**Hack Day の審査対象になるのは、Hack Day の2日間で開発した部分のみです。**
- 拠点ごとにスポンサー賞が用意されているので、スポンサー賞の条件を確認し、「どの賞を狙うか」の作戦を練るのもおすすめ（→ [Sponsor Award](12_sponsor-awards.md)）

## Hack Day当日の流れ

### Day1

- 各拠点チャンネルで共有される会場情報を確認のうえ、会場に来る
  - 会場によっては飲食店やコンビニ等が周りにない場合もあるため、必ず確認する
  - 遅刻・欠席は、必ず各拠点チャンネルで運営をメンションして連絡する
- 会場受付を済ませたら、指定された座席に着席する
- 全体ガイダンスを受ける
- 開発開始
- 終了時間になったら運営からのアナウンスを聞いて解散

### Day2

- 集合時間までに会場に到着
- 簡単なアナウンスを聞いた後、引き続き実装開始
- **Code Freeze 後の 15:30 までに、作品提出フォームを提出する**
  - 作品提出フォームは、スポンサー企業がスポンサー賞を授与するチームを決めるために使用します
  - 作品提出フォームの項目:
    - チーム情報
    - 製品情報リンク（製品情報が掲載された GitHub リポジトリの URL）
    - アップロードした製品説明動画の URL
    - 製品名
    - 開発したプロダクトの「○○ x Tech」、製品概要、審査委員へのアピール
    - 希望スポンサー賞、スポンサー提供物の利用有無
    - 製品の自己評価
    - Award Day に関する質問
    - チームを表す写真1枚
      - ※集合写真や、実際にプロダクトを使用している様子だと👌
      - JPHACKS 広報や、結果発表動画などに使用します
- 開発と並行して、最終成果発表の接続チェックやプレゼンテーション資料作成を行う
- Code Freeze（開発終了）
- 最終発表・デモを行う
  - **Google Meet に接続し、画面録画をしながら行います**（後ほど審査委員が録画を見て審査をするため）
  - **発表の中にはプロダクトデモを含めること**
- 審査時間（参加者は休憩時間）
- 審査発表
  - 各会場のスポンサー賞と、Hack Day Audience Award が発表されます
  - Award Day 進出者の発表は、Hack Day 終了後の審査委員による審査を経て後日発表されます
- 懇親会
- 片付け、解散
