# 開催概要

> 出典: [JPHACKS2026 参加者ガイドライン / 開催概要](https://app.notion.com/p/d1f30d2bd184837fb99601636d01ec15)（Notion 最終更新 2026-10-06、取得 2026-10-24）

## 「イノベーターになろう」

*イノベーターを目指す学生向け日本最大のハックイベント*

JPHACKS（ジャパンハックス）は、学生を対象にした日本最大規模のハックイベントで、2014年より全国の複数都市で開催されています。

開催13周年を迎える2026年は、全国9拠点10会場にて開催します。

オンラインでの事前勉強会（ハッカソンに向けたアイデア創出ワーク）を経て、オフライン予選である「Hack Day（ハックデイ）」をA日程・B日程に分けて実施します。

予選を通過した15チームは、東京大学にて一同に会し本選である「Award Day（アワードデイ）」でピッチを行います。Award DayではJPHACKS Innovator認定のほか、様々な賞を用意しています。

## 全体の流れ

### [前半] Hack Dayの部

プレエントリーからHack Day参加までの流れです。Learning Dayは参加を推奨する事前学習期間（オンライン）です。Hack DayはA日程・B日程に分けて実施し、いずれも**オフライン参加が必須**となります。

参加を希望する拠点がどちらの日程で開催するかをよくご確認のうえ、エントリーしてください。

※Hack Day会場までの交通費支給はございません。

| 日程 | 内容 |
| --- | --- |
| エントリー受付 | プレエントリー／本エントリー |
| JPHACKS説明会 | 参加検討者向けオンライン説明会（質疑応答あり） |
| 事前学習期間 | オンラインでの事前勉強会（アイデア創出ワーク等） |
| Learning Day（参加者向け説明会含む） | オンラインで実施 |
| **10月17日(土)・18日(日)** | **Hack Day A日程（オフライン参加必須）** |
| **10月24日(土)・25日(日)** | **Hack Day B日程（オフライン参加必須）** |

※日程・内容は変更となる可能性がございます

### [後半] Award Dayの部

Hack Day終了後、各会場の発表内容をオンライン審査し、Award Day進出チーム（15〜16チーム）を決定します。進出チームには審査委員からのフィードバックをもとに、オンラインでの追加開発期間（Kaizen Sprint）を用意します。

| 日程 | 内容 |
| --- | --- |
| **10月30日(金)** | **Finalist Day（Award Day進出チーム発表）** |
| 10月30日(金)〜11月15日(日) | Kaizen Sprint（オンライン追加開発期間） |
| **11月15日(日)** | **Award Day（オフライン参加必須）** |

## 1. プレエントリー/本エントリー

### 1-1. プレエントリー（参加者全員）

[JPHACKSのWebサイト](https://jphacks.com/)から、参加希望会場のフォームよりプレエントリーを完了させてください。

- プレエントリーが完了した方には本エントリーのご案内メールを差し上げます
- プレエントリーは**参加を予定される方全員の記入が必須**です。チーム参加の方も必ずチームメンバー全員が完了させてください
- プレエントリーだけでは**参加が確定しておりません**

### 1-2. 本エントリー（チーム登録）

- プレエントリーが完了した方には、運営事務局より本エントリーフォームをお送りします
- 本エントリーフォームは個人参加用とチーム参加用の二種類があります
- チームでの参加を希望する場合はチームの代表者1名が本エントリーを行ってください

※個人参加とは、事前にチームを組まず、運営が編成したチームでハッカソンに参加することを指します。JPHACKSでは必ず2名以上でチームを組んで参加いただく必要があります。

## 2. 参加者発表

- 参加確定者に、JPHACKSのチームSlackへの招待をお送りします

## 4. Learning Day

〜 初めてのオンラインハッカソンに備えて、事前勉強会で準備を進めよう 〜

**10月10日(土) 12:00〜18:00（終日での参加を推奨）**
※12:00〜13:00 参加者向け説明会 / Learning Day は 13:00〜

Hack Day開催前の休日を使って、チームビルディングワークをはじめ、デザイン思考やLean Startup講座をオンラインセミナー形式で開催します。アイデア創発から、Vibe Codingを用いたモックアップ作成までを行い、プロダクト開発の一連の流れを学べます。

### 4-1. Learning Day開催講座一覧

| テーマ | 概要 |
| --- | --- |
| オンラインチームビルディングワーク<br>〜デザイン思考で学ぶチームワーク手法〜 | デザイン思考のアプローチ・概論を学ぶ。発散と収束のアプローチでのチームディスカッション手法を学び、実践する。 |
| ペルソナ策定ワーク<br>〜顧客（ペルソナ）と価値〜 | ユーザ中心設計・顧客視点の重要性を学ぶ。事実・解釈を棲み分けるワークを通じて、独自資産（プロダクトアウト）と価値（マーケットイン）の視点の違いを身につける。ペルソナの定義と共感マップ作成ワークを実施。 |
| アイデア発散ワーク<br>〜ソリューションアイデアの発散〜 | Design Sprintで実践されているCrazy8とソリューションスケッチを用いたアイデア発散手法を学ぶ。 |
| Value Proposition Designワーク<br>〜VPDで実践する顧客課題の発見と解決手法〜 | 「Customer Problem Fit」を検証するためのValue Proposition Designを実践し、顧客の課題発見と解決のアプローチ手法を学ぶ。 |
| 価値仮説の作成<br>〜競合との差別化とエレベータピッチ〜 | Unique Value Propositionの見極め方、競合との差別化の導き出し方を学ぶ。エレベータピッチを作成し、UVPを一文でまとめる。 |
| モックの作成<br>〜Vibe Codingを用いて、アイデアを形にする〜 | 創発したアイデアを、Vibe Codingと呼ばれるAIを使った開発手法で実際に動くモックにする。 |

## 6. Kaizen Sprint（10月30日(金)〜11月14日(土)）

### 6-1. 10月26日(月) AM8:00：オンライン審査

Hack Dayにて提出されたプロダクトの中から、審査委員会にてオンライン審査を実施し、合計15チームのAward Day進出チームを決定します。**審査は10月26日(月) AM8:00から行われるため、審査が開始されるまでは提出したGitHubや動画を含む提出物の更新が可能です。**

### 6-2. 10月30日(金) 18:30〜20:00：Finalist Day（Award Day進出チームの発表）＠オンライン

- Hack Day審査結果とAward Day進出チームの発表
- 協賛企業からの応援コメント
- Award Dayに参加するための詳しい案内

### 6-3. 10月30日(金)〜11月14日(土)：Kaizen Sprint（Award Dayに向けた改善期間）

Award Dayでのピッチや展示会に向けて、各チームがプロダクトの改善を行う期間です。Award Day進出チームには、審査委員からのフィードバックが送られ、それを基に改善を行います。

## 7. 11月15日(日)：JPHACKS Award Day

### 進出チームによるピッチと展示、Innovator認定および各賞の授与

Award Dayに進出したチームは、東京大学・**伊藤謝恩ホール**にて、最終成果発表をオフラインで実施します。

最終的に残った15チームが全体でのピッチ（8分）を行います。発表後は展示ブースを設け、作品の紹介を会場の前で実施します。

その後、組織委員会・審査委員会審査による**JPHACKS Innovator認定**チームを発表。最もオーディエンスから投票を得たチームに贈られる **Best Audience Award**、審査委員会・組織委員会によって最も優れた作品として選ばれる **Best Hack Award** を授与します。また、全チームを対象とした各スポンサーからの **Sponsor Award** の発表を行います。

表彰後は、スポンサー、共催、参加者全員が参加する懇談会を開催します。Award Day進出を逃したHack Day参加者も、最終ピッチの観覧が可能です。
